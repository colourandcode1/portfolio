# colourandcodedesign.com

Holding page for Tony Craig's portfolio — a static, single-file site served via GitHub Pages.

- `index.html` — the entire page (HTML, CSS, JS inline). No build step.
- `CNAME` — custom domain configuration for GitHub Pages.

To preview locally, open `index.html` in a browser, or run a static server:

```bash
python3 -m http.server 4173
# then visit http://localhost:4173
```
